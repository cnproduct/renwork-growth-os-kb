# Industry Packs

行业包不是独立复制的知识库，而是挂载在 RenWork Core 之上的增量配置。它可以增加对象别名、字段、规则、硬停止、来源和评测，但不能改变租户、证据、权限、审计和公开声明底线。

- `export-b2b.json`：当前外贸 B2B 主包；
- `general-industry-template.json`：后续行业包起点；
- `ROADMAP.json`：行业包状态与升级门；
- `industry-pack.schema.json`：机器校验 Schema；
- 十二类出口垂直行业只保留在路线图中；每类都需要独立来源、字段、硬停止、试点和评测后才能激活。

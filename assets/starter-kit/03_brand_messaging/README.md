# 品牌与对外信息口径

## 核心叙事

RenWork 不是一个“会聊天的 AI 工具集合”，而是把企业事实、增长任务、人员审批和持续学习连接起来的业务操作系统。

## 外贸阶段主价值

```text
把产品与市场说清楚
  → 找到有依据的目标企业
  → 区分买家证据与联系人线索
  → 推动询盘、报价、样品和订单
  → 沉淀客户资产与复购机会
  → 用结果持续更新知识与流程
```

## 表达原则

- 结果优先：说“AI 找客户/买家增长”，不要求普通用户理解 Provider/MCP/API；
- 证据可见：管理员能查看来源、核验时间、成本和操作者；
- 能力诚实：区分 AVAILABLE、INTEGRATE、BUILD、FUTURE_RESEARCH；
- 人机协同：自动化服务于判断和执行，但高风险动作有审批；
- 不用恐惧式、保证式或虚假领先表达。

## 禁用表达

“保证成交”“100%真实买家”“无需人工”“一键覆盖所有行业”“零风险”“永久有效价格”。

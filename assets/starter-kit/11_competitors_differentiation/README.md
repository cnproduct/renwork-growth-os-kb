# 竞争对手与差异化

## 替代方案类型

| 替代方案 | 优势 | 常见缺口 | RenWork 建议差异点 |
|---|---|---|---|
| 通用聊天型 AI | 上手快、内容生成强 | 企业事实、流程和权限易漂移 | 证据化知识 + 受控流程 |
| 单一获客数据库 | 数据覆盖和检索成熟 | 线索与后续销售执行割裂 | Provider 抽象 + 客户生命周期 |
| CRM/外贸管理软件 | 记录和流程稳定 | 智能研究、内容和知识复用有限 | 工作流内的 AI 协同 |
| 自动化/Agent 平台 | 可编排性强 | 行业知识、业务红线和交付模板需要自建 | 外贸增长行业包与治理基线 |
| 人工咨询/代运营 | 经验和定制深 | 难以沉淀为企业可复用资产 | 人机协同 + 企业自有知识资产 |

## 差异化边界

差异化表只用于内部定位假设。没有独立证据时，不得声称竞争对手“不安全、没有能力或效果差”，也不得使用无法核验的领先排名。

## 待验证

真实竞品名单、功能、价格、客户反馈、切换成本和赢输单证据。


## 必备输出
- [ ] 竞对类型
- [ ] 痛点—能力—证据链
- [ ] 替换切入点
- [ ] 不可攻击事项

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

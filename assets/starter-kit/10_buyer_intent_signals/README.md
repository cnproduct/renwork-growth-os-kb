# 买家意图信号与机会评分

## 结论

信号只改变优先级，不改变证据等级。单次打开邮件、访问主页或目录匹配属于弱信号，不能单独证明采购意图、交易或决策人身份。

## 必备输出
- [x] 强信号：明确询盘、报价请求、样品反馈、可核验采购证据、复购事件
- [x] 中信号：持续互动、产品匹配、角色匹配、项目时间窗口
- [x] 弱信号：单次打开、访问、模糊目录匹配
- [x] 硬停止：退订、黑名单、争议、营销许可不足
- [ ] 按真实赢单/输单数据校准权重和时间衰减

## 证据
当前 V4 Customer Engine、35 例治理基准和外贸框架。

## 推荐动作
为每次升级保留信号、时间、来源、规则版本和解释，不允许模型无记录改分。

## 红线
评分不是真实性证明，也不能越过退订、黑名单、风险和权限硬停止。

## 待确认
企业实际转化数据、团队容量、阈值、时间衰减和误报/漏报成本。

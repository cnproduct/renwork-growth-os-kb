# 商务政策、订阅、RenCredit 与交付规则

## 结论
当前资料中价格、免费政策、本地/BYOK 和 RenCredit 规则存在历史版本差异。本知识库不选择其中任何版本作为当前对外事实，等待权威价格目录、权益快照和审批记录。

## 必备输出
- [ ] 当前套餐与价格目录
- [ ] 套餐权益、组织/成员配额和模型白名单
- [ ] RenCredit 权威价格表与 quote-reserve-capture-release 规则
- [ ] 退款、开票、合同、交付和服务边界
- [ ] 官方 Plugin 与外部 Provider 成本责任
- [ ] 本地、云端、BYOK、Ollama 的当前批准政策

## 证据
正式商业口径必须来自当前权威目录，而不是历史方案、客户端缓存或单一网页元数据；冲突在得到联合审批前保持显式状态。

## 推荐动作
产品、财务、法务和平台 Owner 联合签署一个版本化商业真相源。

## 红线
不得静默使用本地备用价格替代云端权威目录；不得把沙箱支付或内存账本描述为生产财务系统。

## 待确认
当前价格、权益、税务、付款渠道、退款规则、合同模板和生效日期。

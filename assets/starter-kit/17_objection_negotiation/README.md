# 异议、谈判、风险与审批

## 处理结构

`表面异议 → 真实顾虑 → 需要核实的事实 → 可交换条件 → 回应草稿 → 审批/红线`。

常见类别：价格、MOQ、交期、认证、付款、样品、质量、独家、售后、信任。回应采用 AECR：承认、共情、澄清、重构；不能用未经证实的能力或案例强行说服。

## 自动化边界

- 可自动：识别异议类型、提出澄清问题、生成内部草稿；
- 需确认：条件交换、折扣、排期、认证支持；
- 强审批：底价、账期、独家、重大赔付、合同和收款变更。

## 红线

AI 不得为了“推进成交”绕过权限、硬停止或企业当前政策。


## 必备输出
- [ ] 十类异议
- [ ] 三级强度
- [ ] 可交换条件
- [ ] 绝对红线
- [ ] 审批人

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

# ICP 与买家决策委员会

## RenWork Phase 1 ICP

| 层级 | 组织特征 | 首要问题 | 建议切入 |
|---|---|---|---|
| ICP-A | 有明确产品、外贸团队和客户数据，但系统割裂 | 线索、询盘、报价和客户资产无法形成闭环 | 从一条增长链试点并接入现有数据 |
| ICP-B | 产品和市场明确，获客依赖个人经验 | 找客户效率低、证据不足、跟进不稳定 | 从产品事实 + AI 找客户 + 每日优先级开始 |
| ICP-C | 正在建立外贸能力或数字化基础 | 资料不完整、流程不统一 | 先做知识冷启动和新人路径 |
| No-go | 无明确产品、无 Owner、期待保证成交或绕过合规 | 目标与责任不成立 | 暂缓自动化，先完成业务诊断 |

## 采购/使用角色

- 决策者：老板、总经理、外贸负责人；
- 业务 Owner：销售主管、运营主管；
- 使用者：业务员、跟单、市场、内容人员；
- 审核者：财务、法务、质量、品牌；
- 技术/数据 Owner：管理员、IT、数据负责人。

## 待验证

按规模、行业、数字化成熟度、客单价和销售周期形成真实细分；以上为策略画像，不是已验证市场结论。


## 必备输出
- [ ] ICP分层
- [ ] 采购角色
- [ ] 痛点与成功标准
- [ ] 识别信号

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

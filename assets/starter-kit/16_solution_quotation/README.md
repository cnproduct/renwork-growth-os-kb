# 方案、选型、报价与样品

## 标准输出

| 层级 | 目标 | 必含内容 |
|---|---|---|
| Good | 满足核心需求 | 适用条件、基本规格、核心价格变量 |
| Better | 平衡价值与风险 | 差异点、证据、交付和服务 |
| Best | 高价值定制/长期合作 | 定制深度、验证计划、审批和里程碑 |

报价必须是“条件报价”，明确数量、规格、币种、贸易条款、有效期、交期前提、税费/物流边界和待确认项。样品建立唯一 ID，保存材料、颜色、Logo、包装、确认人、时间和照片/文件版本。

## 红线

没有权威价格、权限或当前有效期时只能生成草稿；不得自动承诺底价、账期、免费样、认证、加急交期、独家或赔付。

## 待确认

各套餐/企业的定价规则、审批矩阵、样品政策、合同模板和电子签署流程。


## 必备输出
- [ ] Good/Better/Best
- [ ] 条件报价
- [ ] 定制深度
- [ ] 样品档案
- [ ] 签样规则

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

# RenWork 知识与自动化治理策略

## 自动化级别

| 级别 | 动作 | 默认策略 |
|---|---|---|
| A0 | 阅读、搜索、摘要、内部草稿 | 权限通过后可自动 |
| A1 | 评分、推荐、下一步建议 | 显示依据，可人工纠正 |
| A2 | 创建任务、生成报价/内容草稿 | 需明确确认后进入正式流程 |
| A3 | 对外发送、发布、批量触达、价格承诺 | 默认人工审批 |
| A4 | 合同、付款、退款、权限、敏感数据导出 | 确定性规则 + 强审批 + 审计 |

## 全局硬停止

- 身份、租户或权限无法确认；
- 退订、黑名单或合法营销许可不满足；
- 来源不足却要求确认买家、交易、联系人身份或企业能力；
- 报价、认证、交期、案例、账期、独家或赔付未经授权；
- 实时数据连接器未配置或返回不可用；
- 涉及跨租户检索、导出或学习；
- 高风险行业缺少专业审核。

## 公开声明闸门

只有 `verified_fact` 或 `public_fact` 可能进入公开内容，且同时满足：

1. `public_claim_approved=true`；
2. 来源可追溯且当前有效；
3. 适用范围、条件和时间明确；
4. 不包含 internal/restricted 数据；
5. 生成内容通过事实、品牌、渠道和合规审查。

## 租户案例

任何客户材料只能保存在对应租户或授权项目空间。通用知识库可以沉淀经去标识、获授权、可复用并审核的方法，但不能保留客户名称、业务数据、联系人、价格、订单或内部表达。

# 产品—市场—买家匹配

## Phase 1 匹配逻辑

```text
企业有明确产品/服务
  + 目标市场或可验证需求
  + 可获取并合法使用的来源
  + 有业务 Owner 和跟进能力
  + 愿意保留人工审批
  → 适合进入 RenWork 外贸增长试点
```

## 推荐试点包

| 企业状态 | 首期包 | 成功标准 |
|---|---|---|
| 资料分散 | 知识冷启动 | 关键事实可追溯，询盘可快速调用 |
| 需要新客户 | AI 找客户 | 候选企业有依据，联系人和买家证据分离 |
| 客户多但失控 | 客户资产 | Account 去重、机会阶段和下一步清楚 |
| 报价转化低 | 销售执行 | 条件、红线、审批和复盘进入流程 |
| 内容口径乱 | 内容与 Claim Guard | 多渠道内容引用同一批准事实 |

## No-go

产品本身、目标市场、合法数据来源、业务 Owner 或跟进能力均不明确时，不应直接承诺自动化增长结果。

## 待验证

各 ICP 的采用率、任务完成率、节省时长、转化改善、续费和支持成本。

## 必备输出
- [ ] 产品×国家×渠道×买家×场景矩阵
- [ ] 推荐等级
- [ ] 证据
- [ ] 首次动作

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

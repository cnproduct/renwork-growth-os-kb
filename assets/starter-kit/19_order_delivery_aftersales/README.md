# 订单、交付、售后与复购

## 订单主链

`商机 → 报价版本 → 客户确认 → 合同/订单 → 收款状态 → 生产/服务里程碑 → 质量/验收 → 交付 → 售后 → 复购窗口`。

每个节点保存主体、版本、时间、责任人、附件、状态和异常。外贸企业 additionally 保存样品/签样、PI、包装、唛头、单证、批次、QC、出货与收款核验。

## 售后分级

- P1：安全、重大质量、批量损失、监管或关键客户事件，立即升级；
- P2：影响使用或交付但可控制，限定时效和责任人；
- P3：一般咨询、轻微缺陷或体验问题，标准流程处理。

## 复购

基于历史订单、产品生命周期、季节、互动和服务结果生成提醒；提醒不是客户已下单的事实。

## 红线

不得根据邮件单方面变更收款账号；重大赔付、退款和合同变更必须走审批和审计。


## 必备输出
- [ ] 订单节点SOP
- [ ] 版本与附件
- [ ] P1/P2/P3
- [ ] 售后证据包
- [ ] 复购动作

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

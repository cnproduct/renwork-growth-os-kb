# 销售内容、SEO/GEO 与多触点话术

## 内容生产链

```text
场景与目标
  → 检索批准事实和品牌口径
  → 生成渠道版本
  → Claim Guard 事实检查
  → 品牌/渠道/合规检查
  → 人工确认
  → 发布或发送
  → 核对目标渠道结果
  → 回流效果与错误
```

## 输出类型

官网、SEO/GEO、B2B 平台、LinkedIn、Facebook、邮件、FAQ、案例、销售材料和培训内容。一个事实只维护一个权威来源，多渠道版本通过引用生成，不复制成互相漂移的“事实副本”。

## 红线

- 生成不等于批准，批准不等于发布，点击发布不等于目标渠道已成功；
- 不使用未批准价格、能力、客户 Logo、案例和认证；
- 不自动发送批量外联或绕过退订/许可；
- 每个渠道分别验证账号、页面、发布时间和实际落地内容。


## 必备输出
- [ ] 开发信
- [ ] 询盘回复
- [ ] 跟进/挽回
- [ ] B2B发品
- [ ] SEO/GEO
- [ ] 多语言FAQ

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

# 目标市场与行业情报

## 结论

RenWork 当前优先服务需要系统化获客、销售执行和客户资产沉淀的中国出口制造企业、外贸公司与工贸一体团队。市场范围必须进一步按产品、国家、渠道、合规和交付能力收窄，不能使用“全球市场”作为可执行定位。

## 必备输出
- [x] 外贸 B2B 通用行业包
- [ ] 12 类出口垂直行业包逐类建档、核验与试点
- [ ] 每类行业的权威法规与市场来源
- [ ] 真实客户使用频率、价值和失败数据
- [ ] 跨行业包优先级验证

## 证据
`SRC-FRAMEWORK-001`、`SRC-REPO-001`、`SRC-USER-001`。

## 推荐动作
先用 3-5 家不同外贸企业验证通用内核，再扩展垂直行业；跨行业从低监管、高共性场景开始。

## 红线
行业 Profile 中的认证、旺季和痛点只是核验起点，不能自动成为企业事实或强制法规结论。

## 待确认
行业包 Owner、目标企业样本、核心任务、法规来源、评测集和退出门。

# 企业身份与可信实力

## 当前公开定位

截至 2026-08-30，`www.rrenn.com` 将人人易 AI / RenWork 定位为“企业级外贸 B2B 增长操作系统与 AI 数字员工平台”。这是对当前官网公开定位的描述，不等于对页面中每项功能作独立生产验收。

## 当前阶段

- 产品主航道：外贸企业 AI 自动化增长操作系统；
- 核心原则：证据优先、租户隔离、可审计、人机协同审批；
- 扩展路径：先完善外贸通用包和垂直行业 Profiles，再扩展其他行业；
- 本知识库不将跨行业路线、连接器、支付或实时数据能力写成已上线事实。

## 对外短简介草案

RenWork 面向外贸企业，把产品知识、买家发现、客户资产、询盘报价、内容触达、订单交付和持续复盘连接成一个可追溯、可审批的 AI 增长工作系统。

该简介为内部草案，尚未通过本知识库公开闸门。

## 禁止夸大项

- “已覆盖所有行业”；
- “全自动成交”“保证获客”；
- “所有海关/CRM/联系人数据均实时可用”；
- “完全无人值守发布和外联”；
- 未经当前权威目录确认的价格、免费政策和权益。

# RenWork AI 自动化增长操作系统知识库 Starter Kit V1.0

> 默认租户：`renwork-platform`
> 当前主航道：外贸企业 AI 自动化增长操作系统
> 扩展方向：稳定行业无关内核 + 可插拔行业包
> 发行状态：公开、去标识的 Skill 模板；不包含客户数据、凭据或原始内部审计

## 1. 产品定位

本 Starter Kit 用于建设 RenWork / 人人易 AI 的知识与操作底座。发行快照所依据的公开站点为 `https://www.rrenn.com/`；发布或引用前必须重新核验当前 canonical、产品能力、价格和政策。

它不把网站文案、代码存在、连接器设计、模板字段或路线图自动升级为已完成的生产能力。

## 2. 建设目标

知识库为人、AI、Skills、MCP、Plugin、Cloud API 和网站内容提供统一底座，重点回答：

1. RenWork 是什么、服务谁、解决什么问题；
2. 外贸企业如何从产品事实走到买家发现、询盘、报价、成交、交付和复购；
3. 哪些信息是事实、建议、规划、待确认、冲突或已失效；
4. 哪些动作可自动执行，哪些必须人工确认；
5. 如何保持租户隔离、来源可追溯和对外口径一致；
6. 如何在不重写稳定内核的情况下扩展到其他行业。

## 3. 三层架构

```text
RenWork Core（稳定、行业无关）
  ├─ 身份、组织、租户、权限、证据、审计
  ├─ 组织/产品服务/客户/机会/交付/风险/指标对象
  └─ 21 模块 ID、知识卡 Schema、公开声明闸门

Growth Operating System（当前主产品）
  ├─ AI 找客户/买家增长
  ├─ 客户资产与商机推进
  ├─ 询盘、方案、报价、谈判、订单和复购
  ├─ 内容、SEO/GEO、社媒与多触点沟通
  └─ 复盘、评测与知识更新

Industry Packs（按需挂载）
  ├─ export-b2b：当前参考主包
  ├─ 出口垂直行业：需要逐包试点
  └─ 其他行业：PLANNED，须逐包验证后启用
```

## 5. 使用顺序

1. 先读 `00_kb_governance/POLICY.md`；
2. 再查 `01_sources_permissions/SOURCE_REGISTRY.json`；
3. 使用 `cards/knowledge_cards.json` 提供可检索知识；
4. 加载 `industry-packs/export-b2b.json` 获得外贸字段和规则；
5. 用 `evals/golden_cases.json` 运行真实问题与拒答测试；
6. 通过验证和审批后，才可提交公开声明或接入内容管道。

## 6. 全局红线

- 不把网页宣传语自动升级为已验收生产能力；
- 不把联系人线索、公开目录或平台匹配升级为真实采购商；
- 买家证据、联系人验证和销售优先级分别评级；
- 未配置真实提供商时返回 `unavailable`；
- 报价、合同、公开发布、批量外联和高风险承诺必须按策略人工确认；
- 客户资料、价格、订单和沟通记录按租户隔离；
- 客户材料只能沉淀为经授权、去标识并审核的可复用方法；
- 未取得当期权威目录前，不固化价格、免费政策或权益。

# RenWork 知识库演进路线

## Phase 1：外贸企业 AI 自动化增长操作系统（当前）

覆盖产品事实、市场与 ICP、买家发现、证据分级、客户资产、询盘、报价、谈判、内容、订单、售后、复购和复盘。

退出门：

- 21 模块结构通过验证；
- 外贸行业包为 `ACTIVE`；
- 关键事实、拒答、跨租户和外部动作评测通过；
- 真实提供商未配置时诚实返回不可用；
- 至少一个非默认客户租户完成隔离试点。

## Phase 2：十二类出口垂直行业增强

逐类建立消费品、食品化工、机械、建材、电子、纺织、汽配新能源、五金、医疗器械、宠物、美妆、户外运动行业包，增加经过核验的字段与候选合规检索词。

退出门：每个行业分别完成产品字段、买家角色、合规来源、旺季节奏、质量红线和 20 条以上黄金评测。候选认证不能直接写成强制要求或企业已拥有证书。

## Phase 3：跨行业业务操作系统

优先验证共性强、监管相对可控的行业包：

1. 专业服务与咨询；
2. 教育培训与协会运营；
3. 零售、电商与品牌运营；
4. 本地生活与连锁服务；
5. 通用制造与项目交付。

每个行业使用核心对象别名映射，不复制租户、证据、权限、审计和学习机制。

## Phase 4：高监管行业

医疗健康、金融、法律、公共服务等必须单独立项，增加专业资质、法律依据、人工审批、数据保存和高风险拒答测试。没有专业审核和生产安全证明时保持 `FUTURE_RESEARCH`。

## 能力状态

| 状态 | 含义 |
|---|---|
| AVAILABLE | 已在当前知识库发行版具备并通过本地验证 |
| INTEGRATE | 已有组件，需要身份、数据、权限或生产服务接入 |
| BUILD | 需求明确，但尚需实现和验收 |
| FUTURE_RESEARCH | 需要法规、数据、商业和技术验证 |

## 架构闸门

- M1：可搜索，不允许高风险自动动作；
- M2：可追溯，事实和公开声明有证据；
- M3：可执行，流程、审批和回滚生效；
- M4：可运营，KCS 双环、AQI 和评测回归稳定；
- M5：可进化，错误集和跨行业复用受控运行。

# 来源、权限与租户策略

## 必须分开的五个维度

| 维度 | 问题 |
|---|---|
| authority | 来源有多权威 |
| status | 结论处于事实、推断、策略、冲突还是待补充 |
| sensitivity | public、internal 或 restricted |
| public_claim_approved | 是否允许进入公开表达 |
| tenant_scope | 哪个组织/项目可以访问 |

## 客户资料隔离

- 客户公司、产品、报价、订单、联系人、沟通和案例原稿只能进入客户租户；
- 通用母库只接收经授权、去标识、可复用的方法和模板；
- 跨租户学习必须记录来源、去标识确认、用户同意、目标资产和审核；
- 没有上述证据时，默认不跨租户复用。

## 能力证据

- 代码存在：只能说明本地实现或候选能力；
- 测试通过：只能说明对应测试范围；
- PR 合并：不等于部署；
- 云端部署：不等于端到端业务验收；
- 页面可见：不等于真实数据、支付、发送或第三方动作已经完成。

# 询盘识别、资格判断与推进

## 十维速检

1. 公司与身份真实性；
2. 产品/规格匹配；
3. 数量与采购频率；
4. 目标市场与合规；
5. 用途和终端场景；
6. 预算/价格敏感度；
7. 交期和项目时间；
8. 定制深度；
9. 决策角色与流程；
10. 风险、许可和下一步承诺。

## 输出

`Go / Hold / Nurture / No-go` + 缺失信息 + 24 小时内下一步动作 + 需升级事项。信息不足时先提出最少的高价值问题，不为追求完整度甩出长问卷。

## 红线

询盘评分不能替代公司验真、营销许可和实际付款/合同风险检查。


## 必备输出
- [ ] 10维速检
- [ ] 三层下钻
- [ ] 24小时动作
- [ ] 升级红线

## 证据
待登记来源、抓取/签发日期和具体定位。

## 推荐动作
补充资料并提交对应负责人审核。

## 红线
未经核验与审批，不得对外承诺价格、MOQ、产能、交期、认证、案例、独家、账期或赔付。

## 待确认
来源、负责人、审批人、适用市场、有效期与公开范围。

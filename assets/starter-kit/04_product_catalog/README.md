## 快速选型

- “我没有系统资料” → 企业知识冷启动；
- “我要找更匹配的海外客户” → AI 找客户/买家增长；
- “线索很多但跟进混乱” → 客户资产与商机；
- “询盘、报价和跟进靠个人经验” → 销售执行；
- “内容多渠道但事实容易漂移” → Claim Guard + 内容工作流；
- “想复制到其他行业” → Core + 对应 Industry Pack，先试点后升级。

## 红线

产品地图是能力导航，不自动证明每项组件已生产部署、已连接真实数据或已取得第三方许可。
